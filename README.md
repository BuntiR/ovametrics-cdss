# OvaMetrics CDSS

Streamlit-based Clinical Decision Support demo for blastocyst grading (college presentation project).

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

App opens at http://localhost:8501

## Deploy on Streamlit Community Cloud

1. Push this folder to a public GitHub repo.
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click **New app**, pick the repo, branch (`main`), and main file (`app.py`).
4. Click **Deploy**.

## Login

Any non-empty email + password works (demo gateway).
